Picoammeter Readout

A desktop operator panel for a low-current measurement setup. Python and tkinter.

This is a simulated stand-in for professional work I can't share publicly. It reuses the same operator panel and the same file-based frontend/backend split, wired to a simulator instead of the real instrument.

What it does

  • Large current readout, auto-scaled from fA up to mA, colored by alarm state.
  • State, stability, gain, temperature, overload, alarm, and connection fields.
  • Zero, set gain, autorange, and high/low alarm levels.
  • Optional temperature correction against a reference temperature.
  • A password gate on every settings change.
  • A built-in simulator, so it runs with no hardware attached.

Run it

This is a desktop app, so it runs locally rather than in the browser:

python picoammeter_readout.py
