# Changelog

## v1.0
- Initial release.
- Large auto-scaled current readout (fA to mA) colored by alarm state.
- State, stability, gain, temperature, overload, alarm, and connection fields.
- Zero, gain set, autorange, alarm levels, and optional temperature correction.
- Password gate on every settings change.
- Frontend evaluates alarms locally, so they work even if the backend is down.
- Built-in simulator backend so the readout runs with no hardware attached.
